# Domain Profile: Troubleshooting & Installation

## Golden Structure
- **Symptom**: Clear description of the error or behavior.
- **Diagnosis**: Steps to verify the root cause.
- **Solution**: Step-by-step resolution, including versions.

## Red Flags
- Articles without dates or specific product versions.
- Ambiguous language ("sometimes", "might", "maybe").
- Missing visual aids or console output examples.

## Retrieval Pattern
- **FAQ/Symptom-based**: Users search for the error message or a description of what's failing.
