# Domain Profile: API & SDK Documentation

## Required Structure
- **Getting Started**: Quickest path to a working request.
- **Authentication**: Clear steps for API keys/JWT.
- **Endpoint Reference**: Full parameter details.
- **Code Examples**: Working snippets in multiple languages.
- **Errors**: Map of HTTP codes to meanings.

## Red Flags
- Naming inconsistencies (mixing CamelCase and snake_case).
- Docs out of sync with actual JSON response payloads.
- Missing rate limit or pagination details.

## Retrieval Pattern
- **Reference**: High-precision lookup of parameters or headers.
