# Domain Profile: JTBD (Jobs to be Done) & Interviews

## Required Structure
- **Job Statements**: "When I [situation], I want to [motivation], so I can [outcome]."
- **Forces of Progress**: Push, Pull, Anxiety, Habit.
- **Micro-interviews**: Transcripts tagged with specific pain points.

## Red Flags
- Documenting product features instead of underlying user needs.
- Lack of emotional or social context for the job.
- Confusing "Who" with "Why".

## Retrieval Pattern
- **Insight/Thematic**: Synthesizing patterns across multiple user interviews.
